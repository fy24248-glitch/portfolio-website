# Simple Portfolio Website

A clean, single-page personal portfolio built with plain HTML, CSS, and JavaScript — no frameworks required.

## Features
- Responsive layout (works on mobile and desktop)
- Sections: About, Skills, Projects, Contact
- Smooth-scroll navigation
- Simple contact form (front-end only — hook up a backend/service if needed)

## How to run
Just open `index.html` in your browser, or serve it locally:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000`.

## Customize
- Edit `index.html` for your name, bio, and project links
- Edit `style.css` to change colors and fonts
- Edit `script.js` to tweak behavior
